# Кинематограф личности — GeoCities edition 0.3

Самостоятельная статическая сборка страницы курса без React, Next.js, CMS и конструкторов.

## Стек

- HTML5
- CSS
- Vanilla JavaScript
- локальные изображения и фоновые ассеты

Сборка не требует `npm install` и может открываться напрямую через `index.html`.

Для локального сервера:

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Структура

- `index.html` — полная страница;
- `styles.css` — визуальная система и адаптивность;
- `script.js` — диагностика, модули и guestbook;
- `DESIGN_AUDIT.md` — технический анализ трёх архивных референсов;
- `assets/` — локальные изображения и оригинальные анимированные GIF;
- `scripts/make_retro_gifs.py` — воспроизводимая генерация GIF-ассетов;
- `scripts/build_single_file.py` — сборка автономного `dist/index.html`.

Чтобы получить один HTML-файл со встроенными стилями, JavaScript и изображениями:

```bash
python3 scripts/build_single_file.py
```

## Публикация

Проект является обычным статическим сайтом. Его можно разместить на GitHub Pages, Cloudflare Pages, Netlify, Railway/Nginx или собственном сервере. Для быстрого независимого превью предназначен автономный файл `dist/index.html`. Для Tilda удобнее использовать опубликованный URL в iframe.

## Контент

Сохранена структура Legacy-версии 22:

1. центральный конфликт;
2. диагностика;
3. шесть модулей;
4. результаты;
5. экосистема и архивные курсы;
6. отзывы;
7. автор;
8. кому подходит и FAQ;
9. следующий шаг.

Дополнительно возвращена таблица форматов участия из презентации курса. Стоимость намеренно не указана: в приложенных исходниках она отсутствует, поэтому перед финальной продажной публикацией её нужно подтвердить.

## Версии

- `course-geocities-vintage-v1` — зафиксированная первая опубликованная версия;
- `course-geocities` — текущая рабочая и публичная версия.

В версии 0.3 одинаковые секции заменены самостоятельными режимами: route map, character select, level select, inventory, world map, guestbook, personal home page, system requirements, help desk и player mode select.

Дополнительные анимированные элементы подобраны в [GifCities](https://gifcities.org/) — архиве GIF с сайтов GeoCities от Internet Archive. В интерфейсе используются прямые архивные URL `blob.gifcities.org`; при включённой системной настройке `prefers-reduced-motion` необязательные анимации скрываются.
